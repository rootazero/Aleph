## What to look for

### Phase 1 — Seam scan
1. **Registration parity** — every `register_*` and the dispatch arm.
2. **CRUD parity** — every `create/update/delete/list/get` and the RPC handler.
3. **Template parity** — every `AgentTemplate` and the resolver that builds it.
4. **RPC handler parity** — every method `rpc_call("agents.x")` and the registered handler.
5. **Stub sweep** — `// TODO`, `unimplemented!`, `todo!`, empty match arms.

### Phase 2 — Enumerate candidates
For each pair, list **file:line for both ends**.

### Phase 3 — Triage (read-first)
For each candidate, grep the consumer side for live callers.

### Phase 4 — Fix recommendations
For each finding:
- file:line of producer
- file:line of consumer (or "no consumer")
- severity (CRITICAL/HIGH/MEDIUM/LOW)
- triage (CONNECT / CUT / DECIDE)
- reason
- proposed fix

### Phase 5 — Guard recommendation
If you find a pattern like `register_*_handlers` being called in boot but `mod.rs` exporting
a different placeholder, suggest a single source of truth.
