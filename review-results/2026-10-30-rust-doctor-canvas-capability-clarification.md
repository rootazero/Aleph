### Tooling

- **graphify** — `graphify-out/graph.json` (139 519 nodes / 288 801 edges) was queried for the module
  semantics (`graphify query "How does the capability lifecycle work from descriptor to ownership lease
  to projection?"`), and a per-module map (files, hub symbols, cross-module edges) was generated by
  `.review/rd-batch3/graph-map.py` and handed to every reviewer as the orientation brief.
- **rust-doctor 0.9.0** — full-workspace scan (`--json --rule rust_doctor::repo::hardcoded_credential=off
  --advisory-db /dev/null`, the Chinese-file panic workaround). 83 diagnostics land in the three
  modules: 27 `expect_used` (repo-wide convention), 21 oversized units, 20 near-duplicate bodies,
  7 duplicate bodies, 4 complex functions, 1 `unused_async`, 1 `unreachable!`, 1 `string_slice`.
  Both single non-structural hits were checked by hand and are **false positives**
  (`src/clarification/session.rs:188` `unreachable!` is a documented constructor invariant;
  `src/clarification/session.rs:699` slices only after walking back to a char boundary).
- **Subagents** — 8 parallel reviewer subagents (read-only, JSON deliverables), then 8 parallel fix
  workers on **disjoint file ownership** (canvas · clarification · capability core · provider/registry ·
  census · projection_host · ownership · facade+zahir_facade).

### Model routing

| Step | Model | Why |
|---|---|---|
| Static review (8 chunks) | `minimax-cn/MiniMax-M3` for the four capability chunks, `minimax-cn/MiniMax-M3.1-Flash` for canvas / clarification / capability-core / provider | complex reasoning → MiniMax-M3 per the task instruction; the smaller chunks need speed, not depth |
| Triage / routing / classification | `typesafe/jev-latest` (`noul`) | calibrated scoring of every P1/P2 finding → `fix-now` (≥0.80) / `verify-then-fix` (0.60–0.80) / `defer` (<0.60) |
| Fix workers | `openai-codex/gpt-6-luna` and `minimax-cn/MiniMax-M3` | implementation work, T1/T2 band |

**Jev was used for exactly three decisions**, all classification/routing with no code generation:

1. *Which findings are real* — one `noul` question per P1/P2 finding (34 scored), asking "is this a
   concrete defect worth fixing now?". Result: 19 `fix-now` (0.80–0.90), 14 `verify-then-fix`
   (0.61–0.79), 1 `defer` (C07-3, 0.59). The P3 items were not scored; they were routed by the
   coordinator on the "doc-drift / no behaviour change" rule.
2. *Which findings a fix worker may skip* — `verify-then-fix` items carry an explicit
   "verify the claim in the code first, and report a false positive instead of guessing" instruction.
3. *Which findings were dropped for cross-module reasons* — the deferral of C04-3 (public provider
   `Starting → Ready` transition) was routed by the coordinator after the worker proved the change
   breaks production callers in `src/gateway/interfaces/feishu`; the revert was coordinator-owned.

Jev was **not** used for: writing code, judging Rust semantics, or accepting the diff — every diff in
this batch was read by the coordinator before it was committed.

## 5. Operator-visible behaviour changes

Memory control for the build: `CARGO_BUILD_JOBS=2` plus the repository's `.cargo/config.toml`
(lld linker), which is what keeps the `alephcore` link inside the 19 GB box. The worktree reused the
target directory populated by the rust-doctor clippy pass, so only the changed crate was rebuilt.

- **Canvas**: deck and frame titles are now validated like the document title (length + control
  characters); per-shape text/label/prompt fields are capped at 64 KiB; deck frame lists are capped
  at `MAX_SHAPES`; a reference-asset list is capped at 64; a document read is capped at
  `MAX_DOCUMENT_BYTES`; a corrupt canvas can now be deleted; a symlink at an asset path is refused
  instead of being treated as a stored asset; a selection with no valid shape id is dropped.
- **Clarification**: a question that reached neither the channel nor any event-bus subscriber now
  fails fast instead of parking for 600 s; the menu is capped at 12 options × 100 characters; the
  model prompt is markdown-escaped and whitespace-collapsed; the first question is published to the
  event bus as well as to the channel.
- **Capability**: an identical `OwnershipTree::register` (same owner **and** lifetime) is
  now a no-op that keeps the incumbent's generation AND its live effect claims; effect-claim
  fencing tokens no longer advance the owner generation (the two counters are separate), so a
  claim can no longer invalidate an unrelated binding's lease; a lease now fails closed with
  `StaleOwner` when the binding's **owner** changed (an ownership transfer), which is what the
  generation alone could not see; a re-entrant `VersionedRegistry::transact`/`close` **panics**
  with an explicit message instead of deadlocking the thread (the mutation lock is poisoned and
  recovered, so the registry stays usable); `bump_runtime` / `revoke_tool` / `dispose_runtime`
  re-check the host state after the mutation and now report `Closed` when the surface died
  underneath the call; the change stream keeps only its most recent 256 changes; `describe` /
  `resolve` report an empty/unknown answer once the registry is closed; a tool's facets now include
  `ExternalEffect` for MCP/extension sources or unsafe replay policy; a terminal effect-claim
  receipt is terminal again, so events after it fail closed.

## 6. Residual risks / not done

- The full 21 k-test suite was **not** re-run; the verification covers the three reviewed modules
  plus `gateway` and `tools` (8 495 tests).
- The 8–10 pre-existing `builtin_tools::browser_tools::qa` failures are untouched by this batch.
- The capability layer's **runtime mount** is still not production-wired (unchanged by this batch):
  `ZahirFacade::new` has no production call site, so several of the fixed guards are only exercised by
  tests.
- The `OwnershipTree::dispose(Runtime)` semantics (tree-wide and terminal) are now **documented** but
  not changed — that decision needs its own architecture approval.
- C08-4 (the ACL of the ownership tree versus the facade's default-visibility bindings) is **open**:
  the implemented fix was reverted because it inverted the ACL and broke the pinned fail-closed
  contracts.
- The census parser hardening items (C05-6 … C05-10) are still open: the census can still mis-read a
  `}` inside a string literal, and a same-named static in one file is still conflated.
- `CapabilityChangeStream`'s history is now bounded at 256, but `invalidate_and_resync` still keeps
  the whole history it is given — a resync delta larger than the bound is truncated.
- The `expect_used` clippy noise (27 sites in scope) was left alone: the crate deliberately uses
  `expect` on invariant-only paths, and the poison-recovery fix removed the ones that were reachable
  from a caller-supplied callback.
