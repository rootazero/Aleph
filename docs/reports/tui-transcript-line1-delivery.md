## 范围与取舍 / Scope and trade-off
- `AppState.messages` 现在是唯一拥有条目的 `shared_ui_logic::transcript::Transcript`，保留字段名及 `Deref<Vec<TranscriptEntry>>` / `DerefMut` 以兼容现有 TUI 只读使用和旧测试；后续收紧可变借用需要一起迁移旧测试与非本任务调用者。生产实时/重放投影只走共享 reducer；`app/trace.rs` 原独立 reasoning/text/tool 投影和 `load_trace_replay` 已 CUT，计费、计划和 overlay 非转录副作用保留。The compatibility mutable deref is an architectural debt, not a second entry store.
- `Transcript::adopt_live_run(&mut self, run_id: &str, now_ms: u64) -> Vec<Change>` 重入同 run 不重置 cursor，新 run 使旧 open step Pending；`Transcript::import_legacy(&mut self, entry: TranscriptEntry) -> Change` 导入本地或老历史行。`apply_replay`/`finish_replay` 遇实时 run 返回 `NeedsResync`，拒绝无水位缝合。
- `app::build_completed_history(session_key: String, generation: u64, rows: &[Value], traces: Option<&Value>, active_run: Option<&str>) -> HydrationResult` 离屏重建有序历史、按 run 回放 trace、缺失/不可解析 trace 回退到历史回答、排除 active run；`HydrationResult::matches` 校验 session/generation。`AppState::apply_completed_hydration(&mut self, result: HydrationResult) -> bool` 在无 live run 且同代时原子替换；`RecoveryState::{Complete, HistoryOnly, Partial(Vec<String>)}` 明示恢复缺口。历史 JSON 缺时间不伪造时间。
- `chat_area` 渲染 Step 标题、状态、运行时片段、折叠详情、分组和嵌套工具；`/detail brief|full` 与 `ALEPH_TUI_DETAIL`/`<aleph_home>/tui-detail`；切换模式清 Step overrides；缓存按 reducer Change、显示宽度、theme/highlight/detail/展开状态失效，已避免每帧对历史正文重新哈希。Tool lookup/toggle 递归处理 Step 内部工具。
