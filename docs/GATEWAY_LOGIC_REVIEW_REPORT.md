## Findings by Category

### 1. Lock Poisoning (Critical)

**Pattern**: `mutex.lock().unwrap()` / `rwlock.read().unwrap()` / `rwlock.write().unwrap()`

**Risk**: If a thread panics while holding a lock, subsequent `.lock()` calls return `Err(Poisoned)`. Calling `.unwrap()` on this will panic, causing cascading failures.

**Fix**: Replace `.unwrap()` with `.unwrap_or_else(|e| e.into_inner())` to recover the poisoned guard and continue operation.
