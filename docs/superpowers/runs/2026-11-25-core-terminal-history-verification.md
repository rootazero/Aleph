- The scopes above were run on `main` at `f4864b17e` — upstream context-recovery work and the authorized transcript reads merged in — after the follow-up that folded the UI surface and repaired the pin. The earlier repair rounds were run twice as well: once on the repair branch and once after `main` merged `7807cf09c`. / 上述范围在 `main` 的 `f4864b17e`（已合入上游 context-recovery 与授权 transcript 读取）上、于折叠 UI 面并修复 pin 之后复跑；更早的修复轮次也跑了两轮：一轮在修复分支上，一轮在合入 `7807cf09c` 之后。
- The refusal the model now sees for an unresolved terminal capability is `tool terminal_capability execution failed: <<<EXTERNAL_UNTRUSTED_CONTENT ...>>> special capability resolution failed: Unknown <<<END_EXTERNAL_UNTRUSTED_CONTENT ...>>`, the same class for a foreign owner and for a session that does not exist. / 模型看到的拒绝文本对「非属主」与「不存在」已是同一类别。
