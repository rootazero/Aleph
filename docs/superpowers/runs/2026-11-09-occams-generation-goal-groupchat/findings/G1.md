## Detailed Findings & Proposed Minimal Fixes

### G1-01: `commit_field_update` unconditionally clears newly set wait barriers on unparked goals
- **File & Lines**: `src/goal/store.rs:1493-1499`
- **Issue**: Unconditional zeroing of requested wait barrier on goals currently without a wait barrier.
- **Proposed Fix**: Remove the lines forcibly setting `merged.waiting_on_task = None` and `merged.waiting_until_ms = None` so updates are preserved.

### G1-02: Double SQLite query and JSON deserialization in `try_claim_continuation_bound`
- **File & Lines**: `src/goal/store.rs:481-499`
- **Issue**: Fetches and deserializes goal JSON twice under the same mutex.
- **Proposed Fix**: Factor `claim_goal_locked` taking the already-fetched `Goal`.

### G1-03: Full `Goal` deep clone in `claim_locked`
- **File & Lines**: `src/goal/store.rs:582-611`
- **Issue**: Deep copies owned `current` solely to compare scalar flags afterwards.
- **Proposed Fix**: Mutate `current` in place and track booleans `baseline_changed`, `workspace_changed`.

### G1-04: Redundant `.clone()`s on fields of owned `live: Goal` in `commit_field_update`
- **File & Lines**: `src/goal/store.rs:1468-1512`
- **Issue**: 8 fields of owned `live` cloned instead of moved.
- **Proposed Fix**: Replace `.clone()` with move.

### G1-05: Unbounded formatting before truncation and double clone in `reopen_after_gate_failure`
- **File & Lines**: `src/goal/pursuit.rs:445, 450-466`
- **Issue**: Interpolates unbounded error string before truncation; clones goal twice.
- **Proposed Fix**: Truncate reason before formatting, clone goal once.

### G1-06: `truncate_chars` allocates a new `String` instead of returning a borrowed `&str` slice
- **File & Lines**: `src/goal/pursuit.rs:27-29`
- **Issue**: Collects into heap `String` at all call sites.
- **Proposed Fix**: Zero-allocation subslice on UTF-8 char index boundary.

### G1-07: Redundant `push_str(&format!(...))` allocations in `render_quota` and `render_lessons`
- **File & Lines**: `src/goal/pursuit.rs:40-42, 109-127`
- **Issue**: Allocates intermediate formatting strings.
- **Proposed Fix**: Use `std::fmt::Write`.

### G1-08: Intermediate `String` allocation in `get_locked` before JSON parsing
- **File & Lines**: `src/goal/store.rs:373-394`
- **Issue**: Rusqlite fetches String into heap before parsing.
- **Proposed Fix**: Parse directly from SQLite's borrowed column memory via `r.get_ref(0)?.as_str()?`.

### G1-09: Redundant intermediate `format!` string allocation in `Goal::new`
- **File & Lines**: `src/goal/types.rs:231-235`
- **Issue**: `format!("{session_id}:{objective}")` solely for hashing.
- **Proposed Fix**: Incremental FNV hash over slices without allocating string.

### G1-10: Repeated `note.to_string()` allocation and session ID cloning in `pause_all_active`
- **File & Lines**: `src/goal/store.rs:1060-1070`
- **Issue**: Allocates String note inside loop for every goal.
- **Proposed Fix**: Allocate note once outside loop.
