## Notes for this batch

`src/cluster/enrollment.rs` is the admission gate: `enroll_node_device` (mint a device
credential), `admit_node` (connect-time admission, returns `NodeAdmission`), `deregister_node`
(`DeregisterError` / `DeregisterOutcome`), plus name matching (`match_by_name`, `match_name_in`,
`unaddressable_name_reason`) and `revoke_node_device`.

External callers already found: `src/gateway/handlers/cluster.rs` (`deregister_node`,
`enroll_node_device`), `src/gateway/server/connection/mod.rs` (`admit_node`),
`src/bin/aleph-server/commands/node.rs`.

Pay special attention to: the `static NODE_NAME_LOCK: Mutex<()>` (every acquisition site -
poisoned-lock handling, held across `.await`?, lock ordering against the registry's `RwLock`),
idempotency of enroll/admit (a reconnecting node must reuse its row, never duplicate),
the unknown-id backfill (must never let a node claim another node's identity),
stickiness of deregistration (a deregistered node stays refused), and the shared
name-matching contract with `registry.rs` (`normalize_node_key`).
