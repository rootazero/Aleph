## Notes for this batch

`src/cli` is the process-side CLI support library consumed by `src/bin/aleph-server/**`: the
gateway endpoint file (`endpoint.rs`), the blocking IPC forwarder used to reach a running
server (`ipc_client.rs`), and the single-instance lock policy (`policy.rs`).

External callers already found: `src/bin/aleph-server/commands/secret.rs`,
`src/bin/aleph-server/commands/resume.rs` (`forward_to_server`, `run_no_lock`, `with_policy`,
`HttpMethod`), `src/bin/aleph-server/commands/gateway.rs`, `.../plugins.rs`,
`.../bootstrap_runtime/mod.rs`, `src/bin/aleph-server/daemon.rs` and
`src/bin/aleph-server/commands/start/mod.rs` (`build_endpoint_url`, `IpcEndpoint::current`,
`write_endpoint`, `remove_endpoint`).

Pay special attention to: the lock-vs-IPC race in `policy.rs` (`lock_or_ipc_dispatch`,
`acquire_or_held`), the loopback-only enforcement and HTTPS policy in `ipc_client.rs`
(`build_client`, `is_loopback_host`, `forward_to_server`), the response size cap
(`CappedBuffer`, `truncate_error_body`), and the endpoint file's atomicity / permissions
(`write_endpoint`, `read_endpoint`, `remove_endpoint`).
