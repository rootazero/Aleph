## Native title-bar option / 原生标题栏方案

The official [Rust desktop title-bar guide](https://nsh.dev/docs/rust/#desktop-title-bars) provides `TitleBarStyle::Hidden`, `title_bar()` insets and `.window_drag(true)` with interactive exclusions. Prefer this approach to `WindowFrameStyle::None`: the latter removes borders and makes the host redraw controls; it does not prove native resize, snap, accessibility or keyboard behavior. On macOS, test hidden-title overlay with native traffic lights first; Tauri already uses an overlay and its existing drag region. On [Windows](https://nsh.dev/docs/windows/) and [Linux](https://nsh.dev/docs/linux/), keep the normal opaque native frame until the supported control/drag path is tested on that OS. Browser rendering must retain no desktop spacer or commands. This is a design assessment, not a shipped chrome change. / 官方 Rust 指南提供隐藏标题栏、原生控件留位和拖动区。优先覆盖原生标题栏，而不是去框后重做窗控。macOS 先验证保留交通灯的覆盖式布局；Windows/Linux 在真机证明窗控和拖动之前保留不透明原生框。浏览器不留桌面空白、不加载窗口命令。本节是设计核对，未实现窗框改动。
