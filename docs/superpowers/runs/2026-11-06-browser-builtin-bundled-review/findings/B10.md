### B10-1 [P1] Target agent ID discarded in `map_bind_error`, producing empty agent name in error message
- Location: `src/builtin_tools/agent_manage/switch.rs:137-147` (`map_bind_error`)
- Failure mode: When `agent_switch` is called with a non-existent agent ID, `bind_channel_agent` returns `BindError::UnknownAgent { agent_id, available }`. In `switch.rs:137-147`, `map_bind_error` matches `BindError::UnknownAgent { available, .. }` and constructs `AgentManageError::AgentNotFound { agent_id: String::new(), available }`. The `Display` implementation for `AgentNotFound` formats `"Agent '{agent_id}' not found. Available agents: ..."`, resulting in `"Agent '' not found. Available agents: ..."` where the requested agent ID is completely blanked out. Both LLMs and human users cannot see what agent was attempted, confusing error triage and model retry logic.
- Evidence:
```rust
        BindError::UnknownAgent { available, .. } => AgentManageError::AgentNotFound {
            agent_id: String::new(),
            available,
        }
```
- Suggested fix: Extract `agent_id` from `BindError::UnknownAgent { agent_id, available }` and pass it directly to `AgentManageError::AgentNotFound { agent_id, available }`. Remove the misleading comment claiming `BindError::UnknownAgent` does not carry `agent_id`.
- Confidence: 1.0

### B10-16 [P3] Non-deterministic `DefaultHasher` used for persistent agent ID generation
- Location: `src/builtin_tools/agent_manage/validation.rs:80-84` (`generate_agent_id_from_name`)
- Failure mode: The docstring claims: "falls back to a deterministic 8-char hash when the slug is empty or too short, so non-ASCII names ('交易助手' -> agent-a1b2c3d4) stay reproducible across runs". However, `std::collections::hash_map::DefaultHasher` is explicitly not guaranteed by Rust standard library to produce consistent hashes across compiler versions or program runs. Across different compiler versions or platforms, the generated ID for the same name may drift.
- Evidence:
```rust
    use std::collections::hash_map::DefaultHasher;
    use std::hash::{Hash, Hasher};
    let mut hasher = DefaultHasher::new();
    name.hash(&mut hasher);
    format!("agent-{:08x}", hasher.finish() as u32)
```
- Suggested fix: Use a stable hash function with guaranteed cross-version determinism (e.g. SHA-256 truncated or a fixed-seed fnv/xxhash) if reproducibility across runs/builds is required.
- Confidence: 0.9
