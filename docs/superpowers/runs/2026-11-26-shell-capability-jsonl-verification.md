# 受控实时 Shell JSONL：#18 准入验收 / Controlled Live Shell JSONL: #18 Eligibility

**结论 / Decision: NO-GO on the current mounted route.** 保留现有 `bash` 启动、限时返回、续读和停止能力；不发布 `stdin_profile`、`write_stdin` 或 `close_stdin`。这不是宿主不支持 cgroup 委派：隔离探针证明本机支持，但现有 Gateway 到 Workspace 的链路没有把撤权、策略或 Capability 变更与最终 pipe 写入排成一条可验证的顺序，driver 也尚未使用经过验证的委派根执行整组回收。 / Retain the existing `bash` launch, yield, read and stop behavior. Do not publish the JSONL launch or input operations. The host can delegate a throwaway cgroup, but the mounted Gateway-to-Workspace path does not order revocation, policy or binding changes against the eventual pipe effect, and the driver does not use the verified delegated root for whole-group cleanup.

依据 / Basis: [批准的设计 / approved design](../specs/2026-11-26-shell-capability-jsonl-design.md) (`1974b6182`) and [执行计划 / execution plan](../plans/2026-11-26-shell-capability-jsonl.md) (`abd2781ef`). Product baseline `854505aa6`; the `src` tree at both revisions is `f5c5920a0bcfb3ea3a9b478e3dbd85aee1632de0`. No changes to product source, tests or Cargo manifests. This report does not retract the [general stdin/EOF no-go](2026-11-26-shell-capability-stdin-verification.md).

## 证据落点 / Source trace

[`src/sandbox/workspace/mod.rs:365–385`](../../../src/sandbox/workspace/mod.rs#L365) invokes those hooks before launch. The probe gives both hooks the same in-memory prepared command, not a running child's stdin. The normalization view has independent expansion/decoding budgets ([`normalize.rs:101–118,155–164`](../../../src/sandbox/command_policy/normalize.rs#L101)), so a raw-byte cap alone is not coverage proof. / 启动前的两套真实判据能覆盖合成整段，不能据此认定运行中每条记录都经同样审核。
- **身份、授权与变更 / Identity, permission and mutation.** [`dispatch_with_caller_context`](../../../src/gateway/server/connection/dispatch.rs#L30) enters the request identity scope; [`caller_identity.rs:153–186`](../../../src/gateway/caller_identity.rs#L153) states exactly what verifies a user and that the connection local does not cross a spawned task. A fresh check followed by a write outside these boundaries still leaves a revocation race. / 角色和作者只用于本轮权限归因，不是可在写入时同步复验的连接授权；Capability 验证也不能替代连接与权限写端。

The throwaway unit was collected; no persistent service, privilege or host permission was changed. / 探针证实可委派，并不代表 Aleph 已接通整组退出或 stdin。
