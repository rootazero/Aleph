## Intent and result / 意图与结果

This bounded slice closes source-owned derived Memory paths without moving raw/session archival into `MemoryRuntime` or creating a universal supervisor. Production Admin API now resolves the current runtime reconciler; startup no longer creates a second unowned reconciler. Runtime-created compression acquires the backend operation at the start of `compress_to_notes()` before per-agent raw reads/consumption, extension dispatch, or file effects. The public `compress()` wrapper resets its turn counter and enumerates unprocessed agent IDs before reaching that guarded path; these preliminary bookkeeping/read operations are not claimed to be admission-gated. Existing callback and raw-session behavior were effect-tested; `FlushRegistry` remains coordination, with derived work gated by the runtime-bound compression service.

本有界切片收紧 source-owned derived Memory 路径，不把 raw/session 归档迁入 `MemoryRuntime`，也不创建 universal supervisor。生产 Admin API 现在解析当前 runtime reconciler；startup 不再创建第二个无主 reconciler。runtime 创建的 compression 在 `compress_to_notes()` 入口获取 backend operation，先于 per-agent raw 读取/消费、extension dispatch 与文件效果。public `compress()` 外层仍先重置 turn counter 并枚举 agent IDs；这些前置 bookkeeping/read 不在 admission claim 内。现有 callback 与 raw-session 行为已通过效果测试；`FlushRegistry` 仍负责协调，其派生工作由 runtime-bound compression service 准入。
