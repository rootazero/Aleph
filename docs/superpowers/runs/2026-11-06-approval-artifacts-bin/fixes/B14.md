# B14 fixes

## F-01 [P1] `revoke_exact` aborts on resolve errors
- verdict: fixed
- files: src/bin/aleph-panel-native-qa-gateway/main.rs:719
- change: Map unknown or already absent devices to `already_revoked`, and map an ambiguous binding to `bad_state`; every expected resolve failure writes a protocol response and continues the loop.
- risk: Unexpected token-store errors still propagate as helper failures because they are infrastructure errors rather than a device state result.

## F-02 [P1] `main()` discards the error
- verdict: fixed
- files: src/bin/aleph-panel-native-qa-gateway/main.rs:257-263
- change: Preserve the machine-readable internal error line and also print the complete anyhow error chain to stderr.
- risk: Error text now appears in operator stderr; stdout protocol behavior is unchanged.

## F-03 [P2] shutdown waits without a timeout
- verdict: fixed
- files: src/bin/aleph-panel-native-qa-gateway/main.rs:797-814, 844
- change: Wake the asset gate during shutdown and bound graceful server joins to five seconds, allowing the helper to emit its lifecycle response when an in-flight request is parked.
- risk: A server task that does not finish in the bound is dropped; this matches the QA helper's bounded teardown contract.

## F-04 [P2] hold swaps the Notify instance
- verdict: fixed
- files: src/bin/aleph-panel-native-qa-gateway/main.rs:109-115, 647, 918-922
- change: Keep one process-lifetime notifier and model the gate as `Idle`, `Held`, `Parked`, or `Released`; repeated holds cannot orphan existing waiters.
- risk: Repeated hold/release commands now expose explicit gate state through the release ack status.

## F-05 [P2] fixture mutex held across stdout I/O
- verdict: fixed
- files: src/bin/aleph-panel-native-qa-gateway/main.rs:503-550, 719-749
- change: Complete fixture mutations inside a scoped mutex guard, then serialize pairing, error, or ack responses after the guard is dropped.
- risk: The fixture mutation remains synchronous and atomic relative to the control loop; response serialization occurs afterward.

## F-06 [P2] release can precede parking silently
- verdict: fixed
- files: src/bin/aleph-panel-native-qa-gateway/main.rs:675-695, 915-923
- change: Track whether the gate was held or actually parked and return `released_before_park` when release did not wake a parked request. A successful `ok` status is reserved for a parked gate.
- risk: Callers that assumed every release ack had status `ok` will now see the diagnostic status for an ineffective release.

## F-07 [P2] stdin line length is unbounded
- verdict: fixed
- files: src/bin/aleph-panel-native-qa-gateway/main.rs:444-458
- change: Reject lines above the 16 KiB protocol limit with `bad_command` before JSON parsing.
- risk: The limit is enforced after `Lines::next_line` has assembled the line, so allocation protection is bounded at protocol handling but not at the Tokio line-reader's internal accumulation boundary.

## F-09 [P2] stopped reports fixture closed while it remains open
- verdict: partially-fixed
- files: src/bin/aleph-panel-native-qa-gateway/main.rs:815-825
