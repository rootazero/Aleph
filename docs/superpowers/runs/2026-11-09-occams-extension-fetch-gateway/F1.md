## Area contracts (invariants that must survive any fix)

### Fetch area contracts (`src/fetch`)

- `FetchProvider` is a **trait contract**: `fetch(&self, url: &str) -> Result<String>` + `name(&self) -> &str`. Public API — do not change signatures or error variants.
- **SSRF**: the *caller* MUST validate the URL against `SsrfPolicy`; providers must NOT re-validate and must NOT attempt DNS pinning (documented limitation). A finding that "provider doesn't do SSRF checks" is a **false positive** — the policy lives upstream. A finding that "provider fetches a caller-supplied URL without re-checking the scheme/host it was configured with" IS in scope.
- **Secret hygiene**: API keys/tokens must never appear in error strings, logs, or `Debug` output. The request funnel must redact the bearer token. Errors surfaced to the user must not leak the credential.
- **Bounds**: response size cap (`MAX_RESPONSE_BYTES`), timeout from config, and the mapping of overflow/timeout into `AlephError` variants are observable behavior — do not change the error variant used.
- **Error semantics**: upstream `success: false` must surface as an error (fail-closed), not as an empty markdown string.
