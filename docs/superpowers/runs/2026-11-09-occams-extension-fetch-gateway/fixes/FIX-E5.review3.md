## New problems

- `src/extension/runtime/wasm/host_functions.rs:327` — `format!("client build failed: {}", e.without_url())` and `format!("request failed: {}", e.without_url())`: `reqwest::Error::without_url` strips the URL from the error display, which also strips the URL from the error message returned to the guest. This is a behaviour change (error strings lose the failing URL) that no finding requested; it is benign for security but changes observable error text.
- `src/extension/runtime/wasm/mod.rs:67` — removal of `#[derive(Debug)]` from `LoadedWasmPlugin`: the struct now holds `Arc<WasmCapabilityKernel>`; if `WasmCapabilityKernel` does not implement `Debug`, the derive would not compile, so its removal may be necessary. If any code relied on `LoadedWasmPlugin: Debug`, this is a silent API narrowing. Cannot confirm without seeing `WasmCapabilityKernel`'s trait impls; flagging as a possible compile/behaviour concern.
