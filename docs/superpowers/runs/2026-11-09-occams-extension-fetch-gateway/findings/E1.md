- **Location**: `/home/zou/data/workspace/Aleph/src/extension/lifecycle.rs:627` (`ExtensionManager::migrate_legacy_disabled_marker`; caller at lines 521–534)
- **Failure mode**: 一个此前仅用 `.disabled` 禁用的项目插件，在首次迁移时遇到 `plugins.toml` 无法保存（例如配置父目录不可写）→ migration 只记录警告并返回，随后 discovery 仍执行 `admit`。失败提交不会更新 live config，因此默认启用的插件被挂载；留在磁盘上的禁用标记并未阻止本轮执行。`/home/zou/data/workspace/Aleph/src/extension/mod.rs:2201–2235` 的迁移测试明确要求本轮 load 就保持禁用；`/home/zou/data/workspace/Aleph/src/extension/lifecycle.rs:4205–4241` 的失败提交测试确认 live config 在保存失败时保持原值。
- **Evidence**:
  > `if let Err(e) = self.commit_plugins_config_locked(candidate).await {`
  > `    tracing::warn!(error = %e, "failed to persist migrated plugin disable");`
  > `    return;`
- **Suggested fix**: 让 migration 返回保存错误，并由 discovery 为该插件记录 inactive/error 行、跳过本轮 admission/mount。保存成功但删除 marker 失败仍可保持现有告警行为，因为 durable disable 已生效。保持配置成功落盘后才发布 live preference、保存失败保留 marker、ClaudeCache 不写入、既有 trust admission 不变；不增加第二份长期禁用状态。代价是此次保存失败会显式出现在加载结果，而不再被当成可继续挂载的成功。
