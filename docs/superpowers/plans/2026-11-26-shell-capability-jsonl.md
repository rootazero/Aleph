# 受控实时 Shell JSONL 实施计划 / Controlled Live Shell JSONL Implementation Plan

> **执行 / Execution:** Use `superpowers:executing-plans` in the isolated checkout. Keep one writer; use a fresh independent reviewer for the final implementation. Steps use `- [ ]` for tracking.

**目标 / Goal:** 允许已授权、有值守的 Agent 在同一个 `bash` 作业中提交 JSONL，在 EOF 前读取固定结果，并关闭输入。只开放有实证的 Linux 路由。 / Let an authorized, attended Agent send JSONL to one supervised `bash` job, read fixed results before EOF, and close input. Release only on a verified Linux route.

**设计 / Design:** [已批准设计 / Approved design](../specs/2026-11-26-shell-capability-jsonl-design.md), `1974b6182`. [通用 stdin 阻断证据 / Generic stdin no-go](../runs/2026-11-26-shell-capability-stdin-verification.md) stays in force. Product comparison base: `854505aa6`.

**架构 / Architecture:** Reuse the scoped Tool, exec approval gate, workspace launch, and supervised lifecycle. A fixed system jq consumes framed data, never a shell program. First prove the text decision, live effect authority, and native profile privately; add the `bash` arguments only after all three pass. The narrow profile makes the proof testable but each additional consumer will need its own proof. / 复用现有入口、审批、工作区准入及生命周期。固定 jq 只吃数据，不执行记录。先验证私有链路，再公开参数；新增消费者以后要单独取证。

**分支与门禁 / Branch and gates:** Only `shell-capability-stdin` in `.worktrees/shell-capability-stdin`; no main change, merge, push, new dependencies, host permission changes, or sudo. Capture QA in a private disposable `HOME`/`ALEPH_HOME`. Do not run concurrent Aleph Core recompiles. Send only synthetic data through fixtures. / 只在隔离工作树写入；验证使用短路径临时 HOME，不改宿主权限，不并发重编 Core，仅用合成记录。顺序 / Order: **#18 → #15 → #16**.

## Task 1: #18 — Prove eligibility without publishing a schema / 先证明可开放，不公开 schema

**现有入口 / Existing owners:** `src/sandbox/{factory,command,security_kernel_hook}.rs`, `src/sandbox/command_policy/mod.rs`, `src/exec/kernel.rs`, `src/sandbox/workspace/mod.rs`; `src/gateway/execution_engine/{turn_permissions,tool_service_builder}.rs`, `src/gateway/handlers/config.rs`, `src/tools/scoped/dispatch.rs`, `src/capability/ownership.rs`; `src/sandbox/{cgroup_v2,shell_lifecycle}.rs`, `src/sandbox/platforms/{common,linux/bwrap}.rs`. Evidence goes to `docs/superpowers/runs/2026-11-26-shell-capability-jsonl-verification.md`.

- [ ] **Check the native environment before product implementation.** Inspect an available disposable unprivileged Linux scope for per-job cgroup creation, effective CPU/memory/PID controllers, process attachment before target execution, and group-empty observation. Reuse the real Workspace/Bubblewrap path for admission and test bounded private scratch, read-only persistence and dependencies, and no network or elevation. Verify the trusted system jq and dependencies are independent of the workspace. Use a short-lived benign descendant to observe real cleanup on natural exit, stop, timeout, and shutdown. Record absent prerequisites as blocked, not passed; do not change the running daemon or host privileges. / 先验非特权委派环境及资源限制，以实际效果证明只读、临时空间上限、原生隔离和整组退出；没有环境就记录阻断。
- [ ] **Characterize the mounted decisions with paired tests.** Start with `command_text_includes_stdin_payload` and `custom_patterns_see_a_script_arriving_on_stdin`. In a private seam, materialize the fixed launch plus the exact accepted frame prefix and candidate bytes through `command_text`; use the mounted `CommandPolicy` decision and the operator hook's normalized `SecurityKernel` decision, factoring pure decision code only where needed. Compare both verdicts and warning vs. block with actual prepared-stdin Workspace admission for built-ins and an operator rule over a harmless multi-record canary. Reject before evaluation if any scan/normalization budget would clip the candidate or accepted prefix. Check a stricter configured budget, policy version change, and preservation of normal launch verdicts. / 使用真实挂载的两套判据做差分验证，包括合成跨记录规则、预算截断、过期版本和旧路径；不另造规则表或重复执行带副作用的 hook。
- [ ] **Prove one canonical live route.** Trace paired request identity, workspace binding, `SessionId`, canonical Capability binding, and effective permission from ingress to the actual writer of each revocable fact. Map mutation and final delivery onto an explicit ordering boundary. Approval can complete outside it, but stale authority, policy, capability, or control must produce zero candidate bytes. Reuse the real permission mutators in barrier-controlled tests; cover revoke, policy change, stop, process exit, and replacement of the binding after approval. A cloned turn config, repeated snapshot, or `OwnershipTree::with_current_binding` callback performing I/O is not proof. If a fact has no shared revocation boundary for this route, leave it ineligible. / 使用真实撤权写端做审批后竞态测量；不得拿快照或禁止 I/O 的回调冒充权限与效果的同步。
- [ ] **Demonstrate a private positive and negative effect.** With a disposable native profile, execute fixed `/usr/bin/jq` directly with literal `-M -c --unbuffered` and the approved filter. Use one existing launch deadline and the same job controller for a nonblocking commit bound by the verified pipe atomic limit. A valid record must yield its expected type/count before EOF; the cross-record block and revoke-wins tests must deliver zero candidate bytes. Keep any T1 spike private and disposable; do not stage it or change public `BashExecArgs`. Pin evidence to the product source and host configuration. / 私有正例须在 EOF 前观测真实 jq，反例须测 pipe 的零候选字节，不开放 schema。
- [ ] **Go/no-go.** Run targeted `cargo test --locked -p alephcore --lib sandbox::command_policy`, `sandbox::security_kernel_hook`, and the affected scoped/workspace tests separately. Proceed only if policy equivalence, live authority and delegated native cleanup have actual positive evidence. If any is missing, commit only the evidence report and identify exactly what remains blocked; do not mark #18 complete, start #15, or claim #16. / 三个门禁均有正例才推进；失败只提交证据，不把验证或终审当完成。

## Task 2: #15 — Wire the existing Bash capability / 接通现有 Bash Capability

**所有者 / Owners:** `src/builtin_tools/{bash_exec,code_exec,process_registry}.rs`, `src/sandbox/{workspace/mod,shell_lifecycle,platforms/common,platforms/linux/bwrap}.rs`, `src/sandbox/exec_approval/{action,gate}.rs`, `src/tools/scoped/dispatch.rs`, `src/session/projection.rs`, `src/harness/agent/{think,act,prompt}.rs`. Keep T1's predicates, grant ordering and Linux ownership in their existing layers. / 策略、权限、IO 仍归原有层。

- [ ] **Red first: launch and framing.** Exercise the existing `BashExecArgs` dispatch with missing vs. explicitly `null` record, conflicting launch flags, non-Linux/unverified configurations, compact UTF-8 and newline framing, frames of exactly 4,096 and 4,097 bytes, the native pipe limit, and the 16 KiB/policy aggregate limit. Verify one newline, no partial frame delivery, and no change to legacy foreground/background/yield behavior. / 先测真字节、缺失 vs. null 冲突及旧行为。
- [ ] **Wire validated inputs to one supervised job.** Add `stdin_profile: "jsonl_inspect"` only for controlled launch with `background` or `yield_ms`. Refuse `cmd`, startup stdin and caller overrides rather than silently ignoring them. Add `write_stdin` with one present `record`, and `close_stdin` with no record. Each pending operation binds the immutable frame to its own attempt in memory; use `ApprovalGate` with `AllowOnce`/`Deny`, no cached grant or second approval on an authorized already-closed result. Revalidate at the T1 effect boundary. Advance the accepted prefix only after one proved complete write; on ambiguous delivery close input, stop under supervision, and never auto-retry. Keep `poll`/`wait`/`read`/`kill` and the cursor on the same process ID. / 仍是同一个 Capability 和作业；审批、写入、EOF 与撤权、停止正确排序。
- [ ] **Red first, then close projections before integration.** Put a unique synthetic canary in valid, denied and malformed calls. Observe assistant events, effective input and traces from both dispatch paths, durable replay, approval records, tool results and the process journal. Project only safe structural fields before the first durable or live projection, even for invalid combinations; preserve pairing IDs. Validate jq stdout to the fixed result shape before it enters live tail or terminal capture; never project raw stderr. Test EOF, backpressure, output progress under a full pipe, and the verified group cleanup outcome. / 覆盖成功、拒绝和非法调用；只投影安全字段与固定结果，不投影 stderr 原文。
- [ ] **Verify the mounted route, not a fake writer.** Drive Gateway → scoped `bash` → live once-only decision → Workspace → Bubblewrap with a deterministic Agent fixture. Check multiple records and non-echoing results before EOF, incremental cursor/no duplicates, repeat EOF authorization, failed approval, cross-session refusal, stop/exit/revoke races and group-empty proof. Use an actual receiving pipe for byte counts and zero-delivery assertions. Run native regressions plus `cargo test --locked -p alephcore --test exec_workspace_jail --test sandbox_capability_approval` and Bash/registry/approval/projection suites. Commit only verified integrated code. / 真的 Gateway、审批、pipe 和 cgroup；不拿标签或 mock 代替实效。
