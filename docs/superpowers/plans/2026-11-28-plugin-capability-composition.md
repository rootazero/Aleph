# 插件导入与 Capability 组合实施计划 / Plugin Import and Capability Composition Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 通过 Aleph 的生产安装、发现、授权和调用入口使用 Claude Code、Pi 与 DeepSeek Harness 的可移植贡献，并独立管理同名项目实例。 / Use portable contributions from the three ecosystems through Aleph’s production entry points and manage same-name project instances independently.

**Architecture:** 由现有适配器选择一次文件快照，交给安装、启动和重载；由配置与发现记录确定实例及其授权，沿现有所有者、registrar 和投影发布贡献。 / One adapter snapshot feeds install, discovery, boot, and reload. Existing config and discovered records determine instance authorization, and existing owners and registrars publish contributions through current projections.

**Tech Stack:** Rust 1.99 workspace, Tokio, serde, `crate::yaml`, existing `glob`/`glob-match`, `sha2`, `EffectScope`, `ToolHandlerRegistry`, `OwnershipTree`, Python Gateway QA.

**Spec:** [插件导入与 Capability 组合设计 / Plugin Import and Capability Composition](../specs/2026-11-27-plugin-capability-composition-design.md), approved at `a06577ceb`.

## 全局约束 / Global Constraints

- 在 `plugin-capability-composition` 隔离工作树完成每次提交。沿用现有 Rust 类型与依赖、Core 的作用域权威和薄 Harness。 / Commit in the isolated worktree. Reuse Rust dependencies, the Core scope authority, and the thin harness.
- 显式安装或现有插件根触发识别，发现只读取数据。保留 Claude 缓存、显式格式优先级及坏清单错误；Pi/DSH 原生代码、安装脚本与 Cordis 动态组合属于后续范围。 / Use explicitly installed packages or existing plugin roots. Discovery reads data. Preserve Claude cache behavior and explicit manifest precedence and errors. Native hosts and dynamic composition remain future scope.
- 项目同名实例占用整个裸名。停用、阻止、失败、缺失贡献各自报告；获准的精确全局调用独立过授权。 / A project instance shadows the entire bare plugin name. Report unavailable states and missing contributions. Authorize exact global selection separately.
- 裸配置键仍属于全局。当前扫描结果不能给项目迁移旧许可或设置。项目没有精确启用选择时，旧裸键的显式禁用仍生效。 / Keep bare config keys global. Current discovery does not attribute old permissions or settings to a project. Retain the legacy deny until an exact activation choice supersedes it.
- 充分授权时，坏候选保留旧版和租约；准入拒绝撤回旧版；提交后故障清理新效果并让旧代际保持失效。 / A defective candidate preserves an admitted incumbent. Admission refusal withdraws it. Post-preflight failure cleans candidate effects and keeps old generations revoked.
- Skill、Agent、Hook 用当前生产入口验收。WASM Tool 和 MCP Tool 用真实注册、调用、租约与撤回验收。MCP readiness 与插件挂载状态分别读取。 / Verify current production capability consumers and call paths. Read MCP readiness separately from mount state.
