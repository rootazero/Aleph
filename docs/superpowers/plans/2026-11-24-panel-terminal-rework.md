# Panel Terminal Rework Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 先修复当前 Panel 终端的显式会话生命周期与断线恢复，再交付 IME、有序输入、复制和有界滚屏。 / Make both current Panel terminals recover reliably and support IME, ordered input, copy, and bounded scrollback.

**Architecture:** Default wide and opt-in modular Webchat keep one `aleph-terminal-ui` presentation and a single recovery controller, with epoch-confirmed coverage supplied by the existing `DashboardState` lease ledger. Rust Core remains the sole PTY/VT and authorization authority; history reads the canonical grid through the existing Terminal Capability. Separate coverage, controller, live interaction and history so each handoff has a testable contract.

**Tech Stack:** Rust, Leptos/WASM, serde JSON-RPC, Canvas, Playwright, Tokio Gateway.

**Spec:** [2026-11-24-panel-terminal-rework-design.md](../specs/2026-11-24-panel-terminal-rework-design.md) (approved 2026-11-24).

## Global Constraints / 全局边界

- Work only on `panel-terminal-rework` in `.worktrees/panel-terminal-rework`; review and commit there. No `main` change, merge or push. No TSX candidate, Desktop IPC/Web v1 expansion, Phone/TUI redesign, default desktop host change, new VT/PTy engine, durable transcript, restart recovery or splits.
- Reuse `PtyTopicLease`, `ClientScreen`, `TabModel`, existing `PtyManager`, live policy and ownership admission. Exactly `pty.screen` and `pty.exit` for terminal coverage. View teardown releases local observers and leases, not the PTY or connection-owned viewport. Do not remove generic Shell subscription behavior.
- Never implicitly spawn, close, execute a command, or replay a possibly delivered effect. Never log or include terminal input, output, clipboard contents or credentials in tracked receipts. Use `MAX_PTY_INPUT_BYTES` (**65,536** bytes including framing), not character count; no partial oversized paste. Preserve Ctrl+C interrupt without a copy gesture and existing terminal modes.
- History is primary-grid, session-local, read-only, authorized like attach, not viewport registration or an event. No write access via v1, search/export, or caching across selection/connection loss. Resolve availability by JSON-RPC code, not translated text.
- Use project lockfile and existing dependencies. `just wasm` must rebuild the tracked default artifact without QA-only features. Modular WASM is separately staged and not committed. Locales and current reference changes are bilingual. Record proof and limitations separately from architecture.

## Review Focus / 审阅重点

| Input or timing | Expected beyond a happy-path test | Owning test |
|---|---|---|
| Second topic resolves after hide or epoch change | Both old leases release; no new listener, UI mutation, or unsubscribe of the replacement | 1: `terminal_coverage_drops_partial_stale_acquisition` |
| A gap occurs during attach replay; no more events arrive | Controller schedules its own bounded retry while keeping the last painted screen | 2: `quiet_replay_gap_recovers_without_another_frame` |
| Browser emits final composition and ordinary input after selection changes | Only active committed text is sent; no stale input, replay, or duplicate | 3: `terminal_composition_commits_once_in_current_selection` |
| A dense styled row exceeds the page budget, or a saved cursor is evicted | Explicit distinct outcomes; no hidden skips, cursor stall, wrapping, or response above budget | 4: `history_page_size_is_bounded_and_does_not_skip_rows` / `history_cursor_survives_append_until_eviction` |
| Alternate-screen transition races an older-page reply; old Gateway lacks history | Stale history never takes over live display; ordinary input/attach still work | 5: `terminal_history_alternate_screen_and_old_gateway` |

**Interfaces:** `PtyHistoryRequest { session_id: String, before: Option<String>, limit: u16 }`; `PtyHistoryResponse { rows: Vec<PtyHistoryRow>, older_before: Option<String>, evicted: bool }`; `PtyHistoryRow { index: String, runs: Vec<PtyStyleRun> }`. Explicit typed error for an individually over-budget or otherwise unavailable page; a valid empty page is success. `PtyToolParams::History { session_id: String, before: Option<String>, limit: u16 }` maps to `PtyOperation::History { before: Option<String>, limit: u16 }`.
