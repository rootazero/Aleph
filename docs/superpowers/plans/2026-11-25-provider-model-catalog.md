# Provider/Model Catalog Implementation Plan / 供应商与模型目录实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make verified recent models discoverable and ensure the exact selected model and configured limits reach execution. / 让经核验的新模型可发现，让执行使用所选绑定和配置限制。

**Architecture:** The existing selectable Capability slot publishes an immutable projection of configured and accepted discovered model choices. Gateway exposes a minimal member view and validates explicit choices against the same facts; Core reuses its metadata merger without confusing discovery with fallback. / 复用现有快照、Gateway 投影及模型事实合并点，区分发现、可用性与自动回退。

**Tech Stack:** Rust, Tokio, serde, JSON-RPC shared protocol, Leptos/WASM, Ratatui TUI. / 沿用现有栈。

**Spec:** [`docs/superpowers/specs/2026-11-25-provider-model-catalog-design.md`](../specs/2026-11-25-provider-model-catalog-design.md)

## Global Constraints / 全局约束

- Work only on `refactor/provider-model-catalog` in the isolated worktree; no `main` changes, pushes, credentials or live account changes. / 仅在隔离分支工作。
- Keep `providers.*` admin-only; member projection contains only usable IDs and display labels. No raw credential in cache metadata, protocol, errors or logs. No network I/O or disk cache read on picker or turn lookup.
- Keep the public `ModelOverride` qualified/raw wire shapes. `Raw` preserves `/`; only the slash command parses shorthand. No qualified-to-default cross-provider substitution.
- Existing provider-level positive context override remains first, then positive matching model definition, then static fact, then existing conservative unknown-model behavior. An explicit token budget still wins. Serving refinement may only constrain the chain budget.
- Do not silently promote an entry to default/fallback, remove an active binding, extend the DeepSeek non-Flash ladder, or add a new transport. No public overlay or importer.
- Use narrow deterministic tests and staged commits. Reuse the current pinned Rust toolchain; honor `AGENTS.md`, Gateway method census/visibility and Core/Interface ownership. / 薄客户端、复用现有 Core；不扩展 Harness 职责。
- Use an independent reviewer for each security- or routing-sensitive seam. Independent native fixtures and source verification may run in parallel; never give two workers the same writable checkout. The parent owns adjudication and final integration; choose models per the operator’s cost/role policy. / 可独立交付的工作并行，写入 worktree 隔离。

## Review Focus / 审阅重点

1. Same endpoint A → B → A while A is fetching must not commit the earlier response (Task 1).
2. `org/model` may be a literal model ID and `org` may also be a configured provider. Do not reinterpret raw RPC requests (Task 3).
3. An old queued choice must not reach a default provider after the requested provider disappears (Task 3).
4. An unknown custom model with an operator context window must shrink the effective budget; another provider's override must not leak across (Task 4).
5. Old Web fetch/selection completion after conversation or picker change must not put the wrong choice in front of the user (Task 2).

### Task 1: Publish accepted discovery / 发布同作用域的发现清单

**Interfaces:** Keep `selectable_models() -> Option<Arc<SelectableModelsSnapshot>>` and boot/config publication. Replace the base-URL-only production discovery entry points with a shared `refresh_configured_models(config: &Arc<tokio::sync::RwLock<Config>>, provider: &str, mode: RefreshMode, resolve_credential: impl Fn(&str, &ProviderConfig) -> Option<String>) -> Result<RefreshOutcome, DiscoveryError>` in discovery. `RefreshMode::{PreferFreshCache, Force}`, `RefreshOutcome::{Fresh(DiscoveredModels), CacheHit(DiscoveredModels), Stale { listing: DiscoveredModels, cause: DiscoveryError }}`. `Fresh` means committed for the accepted scope, not merely fetched. Add `SelectableModelsSnapshot::replace_discovered(&self, provider: &str, models: &[DiscoveredModel]) -> Self` preserving the configured roster plus existing readiness/routability; publish under the slot lock against the current config revision. Existing lookup helpers that take only provider/base URL must not remain production authority.

- [ ] **RED: discovery parsing.** Add `empty_listing_is_authoritative_but_nonempty_invalid_is_shape_error`: `{"data":[]}` yields an empty inventory; `{"data":[{"id":""},{"name":9}]}` yields `DiscoveryError::Shape`; a mixed valid/invalid list still retains usable rows. Preserve the corresponding distinction for each accepted vendor envelope.
- [ ] **RED: publication and race.** Add deterministic local endpoint tests `refresh_publishes_only_current_scope` and `same_scope_failure_keeps_last_good_inventory`. Pause the response, mutate endpoint/protocol/configured credential or remove its provider, then release. Include A → B → A; The scoped cache and live choice must not see the old response. Same-scope failure leaves an existing discovered choice; successful actual empty removes it but leaves an operator model. Also assert an auth- or transport-unavailable provider cannot gain selectable choices from a valid listing, and unrelated providers survive.
- [ ] **Run RED.** `cargo test -p alephcore --lib model_catalog::discovery` and `cargo test -p alephcore --lib session_model_handle`; verify behavioral failures on old logic, not setup errors.
- [ ] **Implement scoped commit.** Reuse the discovery request/decoder/single-flight and existing provider config transactions. Capture effective merged listing endpoint, protocol, resolved credential scope and a monotonic invalidation generation before I/O. Advance the generation on changes to discovery-affecting config/credentials, including deletes, re-adds and vault replacement paths; aggregate with an existing mutation version if available. Recheck current identity at commit under the same publication/mutation authority: a superseded response cannot write even the persistent cache. No lock spanning the vendor request. Compare credential changes only in Core, with opaque scope material; if there is no trustworthy durable revalidation mechanism, do not load that cache on cold start. Derive member-visible IDs from accepted data, never synchronously reread disk for a picker.
- [ ] **Wire both callers and clean up.** Route `handle_models_refresh` and `ListModelsTool::discover_live_models` through the shared entry point and effective credential resolution. `Force` bypasses the ordinary TTL but concurrent calls may join the same scoped fetch; `PreferFreshCache` uses the existing 300-second TTL. Preserve admin stale/error response semantics and tool counts. Update catalog cache consumers and boot/config publishing to share scope semantics; remove old base-URL-only cache read/write paths rather than letting them reintroduce revoked rows.
- [ ] **Run GREEN and commit.** Rerun RED commands plus `cargo test -p alephcore --lib builtin_tools::list_models` and `cargo test -p alephcore --lib gateway::handlers::providers`. Stage Task 1 files; `git diff --cached --check`; `git commit -m 'fix(providers): publish scoped model discovery'`.
