# NSH 整轮语音 / NSH Whole-Turn Voice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 NSH TSX Panel 中交付不显示文字的整轮语音对话；在本机没有可用 STT 配置时使用已安装的离线识别器。 / Deliver voice-only whole turns and installed offline STT fallback on authenticated local desktop.

**Architecture:** Core admits and resolves bounded voice requests, reusing configured STT, chat, and TTS. The Desktop Media boundary owns platform devices and recognition; the shared TSX module drives a turn with an epoch and renders only controls/status. Web v1 uses configured providers only and browser audio I/O, not browser recognition.

**Tech Stack:** Rust/Tokio/Serde, existing DesktopPlatform and macOS Swift Bridge, Windows SAPI, installed Linux whisper CLI, NSH TSX + Rust presentation model, Web Audio, shared v1 framing.

**Spec:** [Approved design / 已批准设计](../specs/2026-11-25-nsh-voice-conversation-design.md) (`9a7ab2720`).

## Global Constraints / 全局约束

- All writes and commits in `refactor/voice-conversation`. No main, Tauri, legacy Leptos UI, default mount, or release migration changes. Move portable VAD only if the classic caller remains wired and behavior stays unchanged.
- `16 kHz mono signed PCM16 WAV`; `20 s = 640,000 PCM bytes + WAV header`. No automatic split, retry of an unknown write, caption RPC, or sentence queue. Existing internal TTS provider fallback remains capped at two provider attempts per logical submission.
- A same-user, active-owner Desktop IPC connection with a mounted local adapter is the only source of offline STT authority. Do not infer it from IP, panel params, session fields, legacy role, or an ordinary Web pairing. Linux endpoint configuration, independently configured offline CLI/model, and macOS/Windows installed recognizers are distinct paths.
- No new model downloads, cloud retry from the offline path, system TTS, automatic acoustic barge-in, or shared-state change to chat retention. Use ordinary Chat's run id, ownership, idempotency and successful terminal summary; discard standard Chat chunks in the voice surface.
- Never log or expose audio, transcript, provider body, local path or credential in voice errors/telemetry. Error UI uses typed reason codes. Externally composable operations go through Capability/typed boundaries. Core never calls a platform API and hosts never choose providers.
- Preserve tests of unchanged consumers; add focused regression tests for the new wire, trust, lifecycle and performance boundaries. Test fixtures are not native device evidence. Stop and report release-gate blockers instead of weakening mounts, authorization or QA.

## Review Focus / 重点风险

1. **Forged local origin:** Web loopback, legacy owner and a caller-supplied `local` flag cannot trigger OS STT or open devices (Task 1, Task 4).
2. **Resource-bound disagreement:** malicious RIFF sizes, a near-limit Web envelope, silence and onset at the duration limit cannot cause over-allocation, invalid playback or auto-splitting (Tasks 1, 4, 5).
3. **Late ownership:** cancellation before `chat.send` returns, wrong run terminal, old audio completion and dispose/reconnect must not enqueue playback or reopen capture (Task 5).
4. **Adapter cleanup:** missing language or model, CLI child timeout, denied capture and a Bridge task that outlives its request must not leak audio, a process or an active device handle (Tasks 2–4).
5. **False success evidence:** an unsupported or oversize TTS response, a dropped terminal frame and a fixture-only run cannot be reported as first audio or as a real native turn (Tasks 1, 5, 6).

### Task 4: Owned capture and native playback / 桌面媒体只接线一次

**Interfaces:** `voice.turn.capture { capture_id } -> { capture_id, limit_reached }` waits for a sealed clip; `voice.turn.capture_ready { capture_id } -> { ready: true }` waits for the first real sample (a short control-only wait); `voice.turn.capture_finish { capture_id }` finalizes a voiced clip; `voice.turn.capture_cancel { capture_id }` drops it. Capture and TTS/playback deadlines are independent; keep the 30 s existing generic NSH RPC deadline for other methods. ## 执行方式 / Execution ownership

Use the user's authorized task-based Pi delegation: contract and cross-module review with a Sol-class model; only parallelize Windows/Linux or read-only platform/QA work with disjoint writers. The parent owns shared protocol and final integration, verifies each child output, and keeps independent final review separate. Frontend/docs can use a lower-cost matching model where available; DeepSeek may only use Flash. Each task is an independently testable deliverable; later UI work consumes the prior contracts rather than inventing parallel ones.
