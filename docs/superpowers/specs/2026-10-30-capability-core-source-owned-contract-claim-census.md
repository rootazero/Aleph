## Reference correction notes — English / reference 校对说明 — English

1. `docs/reference/FEATURE_LOCATOR.md` is a locator and audit history. Its claims must be checked against source before being used as current implementation statements. The current design retains its routing value but does not promote every historical entry to current fact.
2. `docs/reference/ARCHITECTURE.md` already contains the strongest current B8.2 boundary: Feishu has a local provider/cache slice, while A/B/C/D remain NO-GO/deferred. The current Generic Gateway read/lease slice is a separate bounded source-owned contract and does not change that Feishu boundary.
3. `docs/reference/GATEWAY.md` correctly limits Generic Bound lifecycle evidence to bounded proof and excludes Feishu/R2, Zahir routing, all-channel compatibility, crash recovery, durable replay, and external exactly-once. The 2026-10-30 addition records a source-owned async read/lease slice over existing Bound entries without promoting it to production ingress or a universal Zahir mount.
4. The research documents remain valuable for rationale and dated history, but source code controls claims about current behavior.
5. The 2026-10-30 implementation evidence is limited to Generic Gateway Bound read/lease behavior: independent source/descriptor revisions, source-cut describe/list/project/resolve, future-claim and owner-identity fencing, and no-start tests. It does not authorize Feishu wiring, subscriptions, durable recovery, EffectClaim production, Safe Replay, or other provider/kind migration.
