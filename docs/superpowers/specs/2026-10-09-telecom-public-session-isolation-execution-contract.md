## 1. 目的与范围 / Purpose and scope

本契约把“公共上下文”从已经完成的 provenance 传播，收敛为第一个可以真实验收的消费者切片：**已准入的 SMS 公共文本运行只能把固定公共提示和当前电信文本交给同一 Core 的同一 provider 链；在历史、hooks、工作区、memory、routing、skills、goal、工具和 secondary provider 等私有读取发生前，先走公共分支。** 本切片暂不读取跨轮历史；后续加密公共历史必须另行验收。 / This contract turns propagated provenance into the first real consumer slice: an admitted SMS public run may expose only a fixed public prompt and the current telecom text to the same Core/provider chain; it must branch before private history, hooks, workspace, memory, routing, skills, goals, tools, or secondary-provider reads. This slice reads no cross-turn history; encrypted public history requires a later acceptance slice.

本切片**不**实现完整 Task #14、电话、A/B 审批、私有资料读取、主动发送、持久公共历史或真实 Relay。没有证明的来源默认拒绝，不退回 legacy owner path。普通非电信运行必须保持既有行为。 / This slice does **not** implement all of Task #14, voice, A/B approval, private reads, proactive effects, durable public history, or a real Relay. Unproven sources deny; they never fall back to the legacy owner path. Ordinary non-telecom runs remain unchanged.

## 3. 本切片的安全不变量 / Security invariants

1. **入口优先级**：`request.telecom_public.is_some()` 是唯一允许进入本切片的 typed 条件；不得从 `metadata`、手机号、`source_channel`、`role`、`approval_reference` 或用户可写字段推断。未知/损坏/缺失 provenance 不能进入 public runner。 / **Ingress priority:** only typed `request.telecom_public.is_some()` may enter this slice; never infer it from metadata, phone number, `source_channel`, role, approval reference, or user-writable fields. Unknown/corrupt/missing provenance cannot enter the public runner.
2. **前置拒绝**：公共入口必须在 `inbound_router/executor.rs` 的 owner-shaped busy lane、durable queue journal 和任何 owner session 操作之前分流；若公共请求已经进入普通 queue/journal，则该请求必须拒绝，不能事后 scrub。分流后的 public branch 不得调用普通 `admit_run`、普通 owner session 建立、`run_agent_loop`、extension/hook snapshot 或 owner task persistence。 / **Early refusal:** the public ingress must branch before the owner-shaped busy lane, durable queue journal, and any owner-session operation in `inbound_router/executor.rs`; if a public request has already entered the ordinary queue/journal, deny it rather than scrub it later. The branched public path must not call ordinary `admit_run`, owner-session creation, `run_agent_loop`, extension/hook snapshot, or owner task persistence.
3. **同一 Core，不是第二 Agent**：使用现有 Core 的 default provider chain、计费和取消边界，不启动第二个 Agent、云端替代脑或独立模型服务。初始 slice 不读取 owner session 的 sticky model preference、agent-private model hint 或 routing preference；provider resolver 必须由 spy 证明只使用允许的 Core-level default 配置。 / **One Core, not a second agent:** reuse the existing Core default provider chain, metering, and cancellation boundaries; do not start another agent, cloud brain, or independent model service. The initial slice does not read owner-session sticky model preferences, private agent model hints, or routing preferences; a spy must prove that provider resolution uses only allowed Core-level default configuration.
4. **固定公共 prompt**：公共系统提示由 Core 维护的固定常量/显式公共模板组成；不得拼接 SOUL、USER、IDENTITY、AGENTS、workspace instructions、skills、goals、routing recall、host facts、MCP catalog 或 capability ledger。当前电信文本作为唯一动态用户输入。公共分支还必须清除 slash command、`/btw`、steering、model override、workspace override 等普通路径控制字段；不得因文本以 `/` 开头而进入 fast path 或 side-session。 / **Fixed public prompt:** the public system prompt is a Core-owned fixed constant/explicit public template; it must not concatenate SOUL, USER, IDENTITY, AGENTS, workspace instructions, skills, goals, routing recall, host facts, MCP catalogs, or capability ledgers. The current telecom text is the only dynamic user input. The public branch must also clear slash-command, `/btw`, steering, model-override, and workspace-override controls from the ordinary path; text beginning with `/` must not enter a fast path or side session.
5. **无工具初始边界**：public runner 使用 `NullToolService`，tool list/describe 为空，任何 execute 均 fail-closed。未经独立审计的 builtin、heartbeat、MCP、plugin、subagent、extension、background 和 team dispatch 不得由本切片触发。 / **No tools initially:** the public runner uses `NullToolService`; list/describe are empty and execution fails closed. Unaudited builtin, heartbeat, MCP, plugin, subagent, extension, background, and team-dispatch paths must not be reachable.
6. **隔离 session**：初始切片使用专用、进程内、非 owner 的 ephemeral session service；不得把 public 输入/输出写入 `global_session_service`、owner SQLite events、普通 `DmScope`、profile、raw memory、routing store、goal store、result store、hook transcript 或 compaction spill。`busy_queue::durable` 与 crash/manual resume 也不得保存 public 正文；本切片若无法提供 public 专用队列/取消/恢复语义则拒绝排队或恢复，不转入普通队列。没有可证明的隔离 session service 时拒绝运行。 / **Isolated session:** the initial slice uses a dedicated in-process ephemeral non-owner session service; it must not write public input/output to `global_session_service`, owner SQLite events, ordinary `DmScope`, profile, raw memory, routing store, goal store, result store, hook transcript, or compaction spill. `busy_queue::durable` and crash/manual resume must not persist public plaintext; if this slice cannot provide public-specific queue/cancellation/resume semantics, refuse queueing or resume rather than entering the ordinary queue. If the isolated service cannot be proven, deny.
7. **历史边界**：本 slice 默认无跨轮历史；不把 owner history 当作 public history。持久加密 public history（24h / 32 completed turns / 64 KiB per session / 8 MiB per Core）属于后续独立 slice，完成前不得宣称公共会话可恢复或跨 SMS/voice 共享。 / **History boundary:** this slice defaults to no cross-turn history and never treats owner history as public history. Encrypted durable public history (24h / 32 completed turns / 64 KiB per session / 8 MiB per Core) is a later slice; until then, do not claim public resume or SMS/voice sharing.
8. **输出只走已登记的 reply effect**：生成的普通公共回答可以通过当前已准入渠道的 `ReplyEmitter`/channel registry reply effect 返回；它不是 proactive send、private disclosure、tool effect 或 approval grant。公共分支不得伪造 owner session key 来让 `EventVisibilityIndex`、`RunAccepted`、trace 或 spend 账本误把它当成普通 owner run。初始 slice 缓冲完整回答，只在 provider 成功、未取消且 effect fence 仍有效时发出一条普通 reply；取消、provider failure 或不完整输出不得发送。完整回答不得写入 owner/public durable history。 / **Output uses the registered reply effect:** a normal public answer may return through the admitted channel's `ReplyEmitter`/channel-registry reply effect; it is not proactive send, private disclosure, a tool effect, or approval grant. The initial slice buffers the complete answer and emits one ordinary reply only when provider success, non-cancellation, and the effect fence all hold; cancellation, provider failure, or incomplete output must not send. The complete answer is not written to owner/public durable history.
9. **普通路径不变**：`telecom_public == None` 必须继续走现有普通路径；本切片不得改变普通渠道的 owner history、hooks、tools、等待和 approval policy。 / **Ordinary path unchanged:** `telecom_public == None` continues through the existing ordinary path; this slice must not change ordinary-channel owner history, hooks, tools, waiting, or approval policy.

## 4. 拟议最小执行接口 / Proposed minimal execution interface

以下名称是契约名，实施时可采用等价命名，但不能扩大边界： / These names are contract names; implementation may use equivalent names but may not widen the boundary:

```text
HarnessRunner::run_public_text(
    request: PublicRunRequest,
    cancel: CancellationToken,
    events: broadcast::Sender<FlowStreamEvent>,

```

`PublicRunRequest` 至少包含：typed `TelecomPublicContext`、当前文本、run id、取消 token、固定 public prompt 版本、计费/模型选择所需的非私有 Core 配置，以及当前 reply route 所需的不透明句柄。它不得包含 owner `SessionKey`、owner session id、metadata map、workspace path、private prompt、tool override、approval reference 或可由用户伪造的权限字段。 / `PublicRunRequest` must contain at least typed `TelecomPublicContext`, current text, run id, cancellation, fixed public-prompt version, non-private Core configuration needed for metering/model selection, and an opaque handle for the current reply route. It must not contain an owner `SessionKey`, owner session id, metadata map, workspace path, private prompt, tool override, approval reference, or user-forgeable authority fields.

实现可先在 `HarnessRunner` trait 增加带默认 `FlowError` 的概念性 `run_public_text` 方法，避免测试 mock 被静默赋予 public 能力；生产 `AgentHarnessRunner` 显式实现，其他 runner/mocks 默认拒绝。它必须同时定义 public admission/cancellation registry（不能使用 owner-shaped `admit_run` 或让 `/stop` 失效）、public 并发/同绑定串行策略、spend principal 和已登记 `ReplyEmitter` effect。不要把 `_telecom_public` 改名后在普通 `run` 内继续读取 owner 数据来冒充消费者。 / The trait may add a conceptual `run_public_text` method with a default `FlowError`, so test mocks do not silently gain public capability; production `AgentHarnessRunner` implements it explicitly, while other runners/mocks deny by default. It must also define a public admission/cancellation registry (not owner-shaped `admit_run` and not a path where `/stop` stops working), public concurrency/same-binding serialization, a spend principal, and the registered `ReplyEmitter` effect. ## 8. 用户冻结的选择 / User-frozen decisions (2026-10-09)

1. **准入/取消**：独立公共准入表，按 binding 登记；同一号码同时只跑 1 个公共运行；全局公共并发上限；`/stop` 与关闭开关可取消。不使用 owner `admit_run` 或 owner busy lane。 / Separate public admission registry keyed by binding; at most one public run per binding; a global public concurrency cap; `/stop` and the off-switch cancel. 2. **排队/恢复**：拒绝。号码忙时回固定提示（稍后再试）；崩溃后不恢复；公共正文永不写入 durable journal。 / Refuse. A busy binding receives a fixed "try again later" notice; no crash resume; public plaintext never enters the durable journal.

4. **回复方式**：缓冲后经当前渠道回复通路发一条完整回复；取消/失败不发送；不写 owner `RunAccepted`/visibility/trace。 / Buffer and send one complete reply via the current channel reply path; nothing on cancel/failure; no owner `RunAccepted`/visibility/trace records.
