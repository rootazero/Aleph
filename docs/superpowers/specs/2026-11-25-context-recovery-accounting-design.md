# Context recovery and fold accounting / 上下文恢复与折叠计量

## Intent / 目标

Make an existing fold cheap to inspect in a long session. Keep erased ranges unreadable through fold recovery; return authorized text as an ordinary tool result, without expanding the retired prefix back into the working prompt. Reject a manual fold if the summary that actually replaces the old turns is not smaller. Keep Aleph's Rust session store, Tool Capability registrations, and provider usage records as the existing owners.

让长会话按需读取旧折叠。恢复工具拒绝读取已擦除范围；授权读到的正文按普通工具结果返回，不把退休前缀重新展开到 prompt 中。手动折叠只有在实际入模的摘要更小时才提交。复用 Rust 会话存储、已注册的 Tool Capability 和 provider usage 记录。

Exercise the actual handoff; do not add another hook, index or deferred-commit policy. / 先验证已有链，不另做拦截或索引。 |

The operator chose recovery and accounting first. Persistent automatic folding would increase coverage but needs a separate decision on stable prompts, policy, and recovery failures. Starting at tool admission would minimize the first patch, but it would leave two confirmed defects and might duplicate a live path. The chosen route preserves schema and tooling where possible, at the cost of retaining one linear pass over FTS identities on a retired-page request in this slice.

用户选择先修恢复与计量。持久自动折叠覆盖面更广，但要另作触发、失败与前缀策略设计；先改工具入口则可能重复已有生产链。所选方案允许一次线性 FTS 身份扫描，不承诺恢复成本完全与全库大小无关。

A separate synthetic SQLite probe, not a production latency measurement, showed the existing correlated FTS query taking ~0.19 s at 1,000 rows and ~3.28 s at 4,000 rows. Even 10 output rows grow more expensive as the index grows: `CORRELATED SCALAR SUBQUERY` → `SCAN f VIRTUAL TABLE INDEX 0:`. Do not mistake a page limit alone for a fix. 图谱用于定位，最终以源码和生产路径验证为准；合成 SQL 数据仅用于诊断复杂度。

## Recovery contract / 恢复契约

1. **One authority and read snapshot.** Keep model recovery behind the existing `session_decompress` Tool Capability. The dispatcher's injected session remains authoritative; no caller-supplied session or access widening. In the existing SQLite store, one read transaction covers discovery, eligibility and page construction, with no lifecycle or provider await inside it. The operation is a snapshot read, not a lease: clear/rewind committed before a subsequent read is observed on that read; handing a page to the caller cannot retroactively revoke already returned text. Notify the existing restore lifecycle outside the snapshot. The restore operation itself does not write events, unretire rows or insert old messages. The runner still records the returned page as an ordinary `ToolResult` (`src/harness/agent/act.rs`); it can appear in later prompts under normal history rules. Already delivered copies are governed by the retention of the later tool call, not by the old fold's eligibility. / 一次事务读；只接受注入会话；恢复本身不写历史或重新激活旧事件，正常工具回包仍可落盘并进入后续 prompt；旧折叠失去读取资格不追溯撤回已经交付的副本。
2. **Discover by indexed event types.** Load only `FoldRecorded` and `CompactionPerformed`, including retired metadata so nested compactions and legacy checkpoints do not disappear. Use the existing `(session_id,event_type)` index and `list_folds` as the one reconstruction rule. Preserve current default ordering, explicit fold lookups, legacy/recorded de-duplication and foreign-owner degraded reporting. Bound diagnostic enumeration for unknown IDs. A store that cannot implement a snapshot must return explicit unavailability, not “no folds.” / 只读折叠元数据，保留旧 ID、历史折叠与外部 owner 降级；不支持读能力不是空结果。
3. **Validate selected range before emitting any page.** Check inclusive bounds without overflow. Preserve the existing entire-request-range deny rule: even one retired, content-bearing row without an exact FTS witness in the selected range rejects that request, including when the row lies after the first page. Use the existing FTS content predicate (`event_content_text` with the same nonempty test) and witness identity `(session_id, seq)`; do not use a fold record itself, timestamp or retirement generation as proof. Within the snapshot, use one set-wise pass over FTS identities for the selected session/range, not per-row correlated lookups, and scan retired event identities in order. Decode candidate payloads only where a retired row lacks evidence, to distinguish content from markers. An absent FTS table, corrupt required event, or unknown required witness cannot grant access. A witnessed event past the delivered page does not have its payload decoded just to check for corruption; if it cannot be decoded when needed by a later page, that page fails without returning partial text. Do not silently skip corrupt required records; preserve the existing behavior for explicitly ignorable event kinds. Restrict queries to this session/range; no migration or eager full-history reconstruction. Matching keys may be materialized by SQLite; application memory must not hold full unrelated histories or full transcripts. / 整个请求范围先验资格；命中同会话同序号的 FTS 才是现有退休证据，缺证拒绝；不迁移 FTS、不读取无关会话的正文。
4. **Read/render only what is delivered.** Seek the `(session_id, seq)` key and iterate in ascending order, stopping once the budgeted page and continuation are known. Keep ordinary `fold_id`, inclusive `from_seq`/`to_seq`, `next_from_seq`, notes, and the existing renderable-content policy. A page may still inspect markers but must not pre-render remaining event bodies. If one body alone exceeds the page/backstop, extend the tool schema additively with optional `from_byte` and `next_from_byte` (UTF-8 byte coordinates within the rendered body, excluding role/seq label). Use the same `next_from_seq` for that event until its body is exhausted; carry the fold ID and original upper bound. Validate UTF-8 boundaries and reject offsets lacking an explicitly selected fold and start sequence. The role/seq label may repeat; the fragments of the body must concatenate exactly. Fail explicitly if a budget cannot fit even one code point plus required response overhead. Measure the serialized model-visible tool output against the existing single-result hard backstop; never treat downstream head/tail trimming as paging. The existing aggregate turn budget (`src/tools/turn_budget.rs::TurnResultBudget::record`) still applies and may replace the page with a spill marker. This slice does not exempt restore pages, change spill policy, or promise that the cursor survives aggregate overflow. Typed bounds/cursor and explicit unavailable/invalid/denied/empty outcomes belong inside Core; translation to the existing tool result/error occurs once at its boundary. / 序号分页不变，超长单事件用可选 UTF-8 字节偏移续读；守住单结果上限，拒绝不前进的页。整轮预算仍可转存回包，不为恢复绕过预算，也不承诺溢出时游标原样保留。
5. **Replace, don't wrap the old path.** Remove `load_events_with_retirement` / `RetiredEventRow` and whole-session clone, filter, render, and split only if all production and test callers have been moved; retain the shared event content extractor, source store, and fold reconstruction. Leave the existing recall and hard-clear writers unchanged. No new Capability ID, public RPC, service, runner or database. / 全部调用迁移后删除旧的整段读取与中间结构，不新建能力或 RPC。

## Accounting contract / 计量契约

Build the exact content of the persisted `SystemMessage` once (summary marker, framing, optional elision line and body). Estimate that same string for the no-gain guard, `ManualCompactOutcome.tokens_after` and `FoldRecorded.summary_tokens`; retain `ManualCompactOutcome.summary` as the body and leave legacy records unchanged. Preserve the existing comparable dropped-text estimate, compaction input limits, cut logic and atomic retire/summary/checkpoint/fold commit. A body that looks cheaper but is not cheaper when framed must leave history unchanged. Do not describe this local text-token estimator as provider usage or as a complete prompt cost including media, cache re-pay or prices. Keep `core/cache-hit-rate`, `core/fold-economics` and tool `context.breakdown` distinct; document that existing historical fold rows use the old convention and exact cache re-pay is unattributed.

同一份实际落盘并进入 prompt 的系统摘要用于判断、返回与记账；对外摘要正文不变。旧事件不重算，保留切分规则、原子提交及文本估算口径。实际 provider 用量、工具字节和缓存重新计费不得混称节省。

## Verification and delivery / 验收与交付

- Capture on the same checkout a baseline and candidate with real SQLite event-store APIs at comparable session sizes (including a long unrelated tail and a late erased event beyond the first page). Assert zero correlated FTS scans, no unrelated payload decoding, no per-row Rust transcript allocation before paging, and stable output for the same window as unrelated history grows. Record hardware, sizes, timings and working-set characteristics; a dedicated indexed witness is a separate decision if the single FTS identity pass remains material. / 用实际存储路径比较候选与基线，记录尺寸和耗时，不将单次计时写成 CI 阈值。
- Focused regression gates: legacy + recorded collapse, nested folds, foreign-owner fallback, independent sessions, file-backed reopen between pages, hard-retired row before/after the first page, clear/rewind between reads, unavailable FTS, overflow/invalid spans and Unicode across oversized pages. Assert that an authorized page is an ordinary tool result, never a reinserted or unretired past event. Verify lazy decoding with a corrupt later event that still has an FTS witness: an earlier page can succeed, while the read that needs the corrupt row must fail. Exercise Tool Capability dispatch: admitted large output points to retrievable source in scope; structured RPC/media keep their semantics; a restore page keeps its continuation through the single-result hard backstop. Document the unchanged aggregate-turn spill behavior separately. / 验证跨重启、访问隔离、全范围拒绝、UTF-8 和真实能力接线。
- Account for a weak candidate that only loses after framing; assert no writes on rejection and that committed `FoldRecorded` and outcome match the actual summary text entering the prompt. Run focused Core/SQLite tests and checks, plus formatting and diff validation. / 用弱收益用例验证拒绝与落盘一致性。
- Reconcile `docs/reference/FEATURE_LOCATOR.md` §2.1 and §2.7, `docs/reference/CONTEXT_PLUGINS.md`, and any other reference that describes the changed contract. Correct stale fold `summary_ref` and cut description against code, not against old evidence. Commit the reviewed design and, after approval, the implementation and docs on `refactor/context-compaction` only. / 校正事实，提交只落隔离分支。

## Out of scope / 不做

No durable automatic folding, novel spans with holes, provider-cache attribution, provider fees, import of the two plugins, independent storage or new access paths, media reconstruction, main updates, or push. Existing FTS remains best effort and searchable body is not the source of recovered text. This does not change the retention contract of the separate tool result store, durable usage records, or backup media; “hard-retired” here means denied by the session recall/restore path, not physical erasure from disk.

不做持久自动折叠、有洞范围、账单归因、参考项目移植、额外存储、媒体恢复、main 修改或推送。会话逻辑擦除不等于磁盘物理擦除，不改变工具原文存储等其他系统的保留策略。
